# Double Slit Experiment Simulator

A visualiser of the double slit experiment and conditions manipulation.

Set up your own conditions using the parameter tuning feature, then run and view your simulation. Learn how the physics and mathematics behind the project work, and how to implement it yourself, by reading the [guide](Guide/Double_Slit_Experiment_Simulator_Guide.pdf).

Built completely in C++ using the Qt framework, for educational and scientific purposes.

---

## Features

- **Animation window** displaying the particle's evolution in time throughout the experiment, with the possibility to pause/resume.
- **Parameter tuning** capacity: modify the particle's starting position, momentum and size, along with the space between the slits and their position.

---

## Tech Stack

- C++ / Qt
- Legacy code includes the visualisation implemented in Python using Matplotlib
